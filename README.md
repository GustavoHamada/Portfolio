## 🎨 Tema
**Peppa Pig** — rosa, divertido e cheio de personalidade!

## 📁 Estrutura
```
portfolio/
├── index.html       ← estrutura e conteúdo
├── style.css        ← aparência e design
├── script.js        ← interatividade
├── README.md        ← este arquivo
└── imagens/
    ├── foto.jpg         ← sua foto ou avatar
    ├── construct.png    ← captura do jogo
    └── processing.png   ← captura do app multimídia
```
